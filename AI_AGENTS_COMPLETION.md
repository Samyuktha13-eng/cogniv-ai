## Complete AI Agent Pipeline

The system now has a complete end-to-end pipeline for generating game
blueprints from patient goals:

```
Natural Language Goal
    ↓
Goal Agent (parse intent)
    ↓
Memory Agent (retrieve context)
    ↓
Story Agent (generate narrative)
    ↓
Game Agent (convert to gameplay)
    ↓
Blueprint Validator (check integrity)
    ↓
JSON Blueprint (ready for execution)
```

### Files Created

1. **backend/agents/goal_agent.py** (~280 lines)
   - Parses natural language goals
   - Extracts target type (person, place, food, family)
   - Identifies cognitive objective (recognition, association, etc.)
   - Builds memory chain hints

2. **backend/agents/memory_agent.py** (~330 lines)
   - Loads patient memory repository
   - Retrieves relevant entities based on goal
   - Builds composite memory associations
   - Recommends memory progressions

3. **backend/agents/story_agent.py** (~400 lines)
   - Generates 8-scene narrative structures
   - Creates branching scenes (correct/wrong paths)
   - Builds memory chains within scenes
   - Establishes scene-to-scene flow

4. **backend/agents/game_agent.py** (~220 lines)
   - Converts Story objects to GameBlueprint
   - Maps semantic action IDs to options
   - Extracts asset references (characters, environments, foods)
   - Creates scene blueprints with structured actions

5. **backend/agents/orchestrator.py** (~420 lines)
   - Coordinates all agents
   - Async/await execution pattern
   - Error handling and recovery
   - Metadata tracking with timing
   - Blueprint validation
   - Caching for performance

6. **backend/agents/__init__.py** (~25 lines)
   - Exports all agent classes
   - Clean module interface

# 2. ARCHITECTURE HIGHLIGHTS

## Key Design Principles

### Separation of Concerns
- **AI Layer** (agents): Generates logic, structure, narrative
- **Media Layer** (assets): Pre-created animations and images
- **Database Layer** (storage): Patient profiles, outcomes, blueprints
- **Execution Layer** (runtime): Unity playback of blueprints

### Semantic Actions (NOT filenames)
```python
# Blueprint uses semantic IDs
action_map = {
    "person_anu": "daughter_recognition_success",  # SEMANTIC ID
    "wrong_option": "wrong_answer_encouragement"
}

# Asset manifest maps to files
{
    "daughter_recognition_success": "assets/animations/daughter_appear.mp4"
}
```

This allows:
- AI to generate logic without knowing media details
- Easy updates to animation library
- Clear separation between what AI generates and what humans create

### Two Execution Loops
```
┌─ Real-time Gameplay Loop (Immediate) ──────┐
│ Patient Button → Action Router → Animation  │
│ Response Time: ~100ms (local)               │
└─────────────────────────────────────────────┘

┌─ Personalization Loop (Background) ────────────┐
│ Outcome Recorded → Profile Updated →           │
│ Next Game Generated by AI Agents               │
│ Latency: Acceptable (async)                    │
└──────────────────────────────────────────────┘
```

## Modified Endpoint

### POST /game/create
```
Endpoint: POST /game/create
Input:
  {
    "patient_id": "Patient_001_Lakshmi",
    "goal": "Help Lakshmi remember her daughter Anu"
  }

Processing:
  1. Initialize AIOrchestrator
  2. Call await orchestrator.create_blueprint(patient_id, goal)
  3. Wait for blueprint generation (async)
  4. Validate blueprint
  5. Store in _game_blueprints cache
  6. Return GameCreateResponse with first scene

Output (on success):
  GameCreateResponse {
    blueprint_id: str,
    game_id: str,
    story_title: str,
    patient_id: str,
    validated: bool,
    validation_errors: List[str],
    first_scene: SceneBlueprint
  }

Error Handling:
  - Blueprint generation failure → 500 Internal Server Error
  - Invalid patient → Memory agent returns error
  - Validation failure → validation_errors listed in response
```

## Creating a Game

### Option 1: Direct API Call (PowerShell)
```powershell
$body = @{
    patient_id = "Patient_001_Lakshmi"
    goal = "Help Lakshmi remember her daughter Anu"
} | ConvertTo-Json

$response = Invoke-WebRequest `
    -Uri "http://localhost:8000/game/create" `
    -Method POST `
    -ContentType "application/json" `
    -Body $body

$blueprint = $response.Content | ConvertFrom-Json
Write-Output $blueprint | ConvertTo-Json -Depth 5
```
